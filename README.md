# WiKall v2 المحلي

تطبيق Android 10 فأحدث للمكالمات المحلية. يعمل هاتف **Master** برقم
`99000` كدليل وإشارات TLS، ويعتمد ما يصل إلى 30 هاتفًا. أرقام العملاء
من `99001` إلى `99999`. لا يحتاج تشغيل المرحلة المحلية إلى خادم Python
أو حساب Firebase أو خدمة إنترنت.

## التشغيل

1. فعّل Wi-Fi أو نقطة اتصال مشتركة. افتح التطبيق على هاتف Master وشغّل الخادم.
2. شارك طلب تفعيل Node مع المسؤول وحدد رقمًا ثم استورد الملف أو امسح QR.
3. اتصل بالرقم من شاشة الاتصال. لاستخدام EasyTier وافق على طلب VPN.
   تبقى معلومات التفعيل عند الانتقال إلى شبكة محلية أخرى.
4. افتح «الرسائل المحلية»، أدخل رقم المستلم ثم اكتب الرسالة وأرسلها.
   يحفظ الدليل الرسائل المشفّرة للأجهزة غير المتصلة إلى أن تستلمها.

## البناء والاختبارات

يتطلب البناء JDK 17 وSDK 35. شغّل `./gradlew assembleDebug` لإنتاج
`build/outputs/apk/Wi-Call-v2-Offline-Debug.apk`. ثبّت الملف نفسه على كل
هاتف واختر دور Master أو Node من شاشة البداية. راجع [بناء JNI](OVERLAY.md) قبل تجميع APK
مخصص لاختبار النفق، و[مصفوفة الاختبار](TESTING.md) قبل اعتماد الإصدار.
